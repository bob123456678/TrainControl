## Stage D — Know about, nothing to do (10 min)

**22. A graceful stop now takes a moment longer to report itself finished** — and is telling the truth
for the first time. `isRunning()` was blind to a locomotive between deciding where to go and departing,
so the layout called itself stopped while a train was one instruction from moving, and every "is it
safe to edit" check believed it. If it feels *slow* rather than a moment, tell me.

**23. A Stop pressed while a train is mid-sleep still waits that sleep out** — bounded by your delay
setting, or 30 s for the yield wait. Much smaller than the indefinite hang it replaced, not zero.
Making it zero means interruptible waits everywhere.

**24. Two long-standing faults could take the power off a healthy layout**, and both are fixed. One
lost ping response used to end the keepalive for the whole session — "lost connection" for ever, and
under autonomy the latency cutoff firing every five seconds, including five seconds after you turned
the power back on. Separately, any short system frame from anything else on the CAN bus read as an
emergency stop. If either has ever happened to you and you put it down to the layout, it was this.

**25. If TrainControl ever failed to read `LocDB.data` at startup, it used to save an empty one over
it on the way out.** Now the unreadable file is copied aside first and the log says where. Your
database is fine — this is about the next time.

**26. Nine entries removed from the 3.0.0 changelog** as bugs that only ever existed on this branch.
The judgement call is *"trains stopped moving even though routes were available"*.

**27. `Automation.md` is now the user guide**; the JSON and API reference moved to `AutomationAPI.md`.
**Removed from the diagram editor:** paste-entire-row, paste-entire-column, the four
shift-the-whole-diagram items, and `Shift+C`/`Shift+R` — multi-select replaces them. **The condition
editor offers only accessory and feedback kinds**; others produce a permanently false condition, and
an existing auto-locomotive condition is preserved read-only.
