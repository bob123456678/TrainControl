# Archived reviews

Reviews whose every finding is closed, and plans that have been carried out. Nothing here needs
anybody's attention; it is kept because commits, changelog notes and other reviews cite these
identifiers, and a citation that leads nowhere is worse than a long folder.

**A document moves here when its overall status becomes `closed`, and moves back the moment it becomes
`reopened`.** The rules are in [../README.md](../README.md) under "Archiving".

Nothing in here is authoritative about the code as it stands now. A finding closed in July was closed
against July's code; if the same area has since been rewritten, the archived document says what was true
then, not what is true today.
