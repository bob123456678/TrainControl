# Feature requests

Adam writes here. Claude reads here, moves what it finds into [tests.md](tests.md) as tracked entries,
and clears this file back to empty.

**How to use it:** put anything you want built under **Inbox** below, in whatever form suits you - a
sentence, a paragraph, a sketch. There is no format to follow and nothing to fill in.

**What happens next:** at the start of the next round, Claude picks up everything in the Inbox, gives
each item an `MT-###` tag in `tests.md` with the disposition **needs test**, notes here-is-where-it-came-
from, and empties the Inbox. From then on the request is tracked like everything else: it appears in the
ledger, it gets worked when you ask for it, and it only reaches **fixed validated** when you say it
works.

**Requests are not worked the moment they are filed.** Filing puts it on the list; asking gets it built.
That split is deliberate - it lets you write something down the moment you think of it without deciding
then and there whether it is worth doing now.
