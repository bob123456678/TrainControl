MT-380: the one-page layout to import a five-page export into.

Trimmed from the five-page layout shipped for MT-244 - a real layout off Adam's railway - down
to its first page, '1 - Main'. The other four pages, their entries in gleisbild.cs2, and the
three page-link arrow tiles that pointed at them are removed; an arrow holds a page's POSITION in
the name-sorted list, and a one-page layout has nowhere for one to point.

There is no autonomy setup in it, which is what the step asks for: 'a one-page layout with
nothing set up'. The five-page EXPORT is yours - Autonomy > Export, from your own railway - because
the test is about an export's page names being matched against this layout's.
