# Citation index - retired 2026-09-08

Replaced by **[`docs/reviews/findings.md`](../reviews/findings.md)**, which does the same job for every
finding rather than only the cited ones, and is generated by
[`docs/tools/catalog-findings.py`](../tools/catalog-findings.py) - a script in the repository, where it
can be read and corrected. The two generators behind this file lived in a scratch directory, which is
the fault `one.sh` had: a tool nobody can see is a tool nobody can review.

The ids that resolve to nothing are rolled at the foot of the catalogue, with the files that cite each
one. `testEveryCitationResolves` holds that count so it cannot grow quietly.

The retired version is in git history at `1b3d7b7d`.
